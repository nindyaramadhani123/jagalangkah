# Jaga Langkah – Kampanye Sosial Anti Perdagangan Orang

Blog satu halaman untuk tugas mata kuliah **Aplikasi dan Teknologi**. HTML, CSS, dan JavaScript murni, tanpa folder tambahan.

## File

```
index.html
style.css
script.js
README.md
```

## Deploy ke GitHub Pages

1. Buat repository **Public** baru di GitHub (misalnya `jaga-langkah`).
2. **Add file, Upload files**, seret `index.html`, `style.css`, `script.js`, lalu **Commit changes**.
3. **Settings, Pages**: Source **Deploy from a branch**, branch `main`, folder `/(root)`, lalu Save.
4. Tunggu 1 sampai 2 menit. Blog terbuka di `https://USERNAME.github.io/jaga-langkah/`.

## Sebelum dikumpulkan

- Tambahkan nama penulis atau kelompok di footer (`index.html`, bagian `<footer>`).
- Cek ulang nomor dan nama lembaga di bagian Bantuan lewat situs resminya.
- Font dimuat dari Google Fonts, jadi perlu internet saat dibuka.
